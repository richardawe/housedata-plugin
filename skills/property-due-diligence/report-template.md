# Pre-bid report structure

Fill in every section below from the tool data actually returned — do not invent a value for a section with no data, mark it as unknown/not available instead. Keep the whole report to something readable in two minutes.

---

## [Address], [Postcode]

**Headline:** One or two sentences — what this property is, and whether anything found is a hard blocker. No verdict on price or whether to bid.

### Flags (ordered by importance, most urgent first)

For each flag: what was found, why it matters for a cash buyer, and the cheapest realistic next step to resolve or confirm it before bidding. Omit this section entirely (don't write "no flags found") if there genuinely are none — say so in one line instead.

### At a glance

| | |
|---|---|
| EPC rating | current rating, score, lodgement date |
| Floor area | current, and prior EPC's figure if it changed |
| Last sale | price and date, or "no Price Paid record" with the likely reason |
| Flood risk | river/sea zone and surface-water risk, reported separately — never collapse to one word if the tool returned two |
| Planning | area approval-rate/score, and any live nearby applications |
| PRISM consent-gap score | score and top remediation path, or "not available on this plan" |

### What the data doesn't cover

The fixed list from the skill (tenure/title, survey, legal searches, data lag) — trim only if genuinely irrelevant, don't pad it.

### Suggested pre-bid actions

Concrete next steps sized to the deadline the user gave you — e.g. "ask the agent whether the loft conversion has building-control sign-off" beats "investigate further." Include cost/timeline only where PRISM or another tool actually supplied it.

---

*Data sources: cite whichever of EPC Register, HM Land Registry Price Paid, Environment Agency, planning authority registers, and PRISM were actually used, each with the date the tool call was made. Do not present anything from this report as a substitute for a solicitor's searches or a physical survey.*
