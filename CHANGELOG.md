# Changelog

## 0.1.1

- Add plugin icon (`assets/icon.png`, 512×512) and `privacyPolicyUrl` (https://housedata.uk/privacy) to the plugin manifest.

## 0.1.0

Initial release.

- MCP server (`https://housedata.uk/mcp`) with 11 read-only property lookup tools: `search_property`, `get_property_summary`, `get_epc_history`, `get_price_history`, `get_area_market`, `get_flood_risk`, `get_planning_history`, `get_broadband`, `get_prism_score`, `check_epc_compliance`, `get_grants`.
- `property-due-diligence` skill and `/housedata:report` command.
- `landlord-epc-compliance` skill and `/housedata:portfolio` command.
- Setup skill guiding first-time API key configuration.
